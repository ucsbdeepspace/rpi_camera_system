Classic global-npm-prefix permission issue — the fix is to point npm at a directory you own instead of using sudo (avoid sudo npm install -g, it causes more permission headaches down the line):

mkdir -p ~/.npm-global
npm config set prefix ~/.npm-global
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
npm install -g @anthropic-ai/claude-code

That creates a local npm directory in your home folder, tells npm to install global packages there instead of the system-wide /usr/lib/node_modules, and adds it to your PATH so the claude command is found afterward.
